# **App Name**: ResultFlow

## Core Features:

- Marksheet Format Management: Allow University Admins to define and manage standardized marksheet formats.
- Grading Policy Management: Enable University Admins to define and manage grading policies (e.g., A = 70–100, B = 60–69).
- Marksheet Parsing and Mapping: Provide a tool to automatically parse uploaded marksheets and map scores to student records.
- Result Generation: Generate individual result sheets per student and broadsheets (summary of all student results in the department) automatically.
- Student Result Access: Enable Students to log in, download individual result sheets in PDF format, view previous semester results, and track CGPA progression automatically.
- PDF Export: Export student result sheets and broadsheets as PDFs.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability.
- Background color: Very light blue (#F0F2F8), almost white, providing a clean and professional backdrop.
- Accent color: A slightly brighter purple (#7C4DFF) used sparingly to draw attention to important UI elements.
- Font pairing: 'Inter' (sans-serif) for body text, combined with 'Space Grotesk' (sans-serif) for headers.
- Use simple, outlined icons to represent different actions and sections, maintaining a consistent and clean aesthetic.
- Design the layout to be clean and structured, ensuring easy navigation and quick access to information. Utilize white space effectively to avoid clutter.
